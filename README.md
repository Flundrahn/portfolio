
# Portfolio
This is a simple static React SPA that was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

## Highlights

Built during Salt's post graduation program as a personal portfolio but primarily as practice of frontend skills. I learned Framer Motion to animate the app and include some interactive and draggable components, also experimented with CSS-driven layout/animation. I also wired a GitHub API flow that fetches README.md files for showcased repos and renders them in a GitHub-like style, to automatically keep the included repos descriptions up to date.

## Getting Started

### Prerequisites

- Node.js 24+
- npm 10+

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000).

### Other useful commands

```bash
npm test
npm run build
```
